# Code of Conduct

## Our standard

Participation in this project — issues, pull requests, discussions — is
expected to stay respectful and constructive. Disagreement on technical
direction is normal and welcome; personal attacks, harassment, or
discriminatory language are not.

## Scope

This applies to all project spaces: issues, pull requests, discussions, and
any other official communication channels for this repository.

## Enforcement

Instances of unacceptable behavior may be reported by opening an issue
tagged appropriately, or by contacting the maintainer directly. Reports
will be reviewed and addressed at the maintainer's discretion, which may
include warnings, comment/issue removal, or blocking repeat offenders from
the repository.

## Attribution

This is a lightweight, project-specific code of conduct rather than an
adoption of a longer external template — appropriate for a solo-maintained
open-source project at this stage.
