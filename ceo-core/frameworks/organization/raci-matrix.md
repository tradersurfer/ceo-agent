# RACI Matrix Framework

## Definition
Clarify decision and delivery roles as Responsible, Accountable, Consulted, and Informed.

## When to Use
Project governance or decision-rights clarity.

## Execution Steps
1. List project tasks/milestones vertically.
2. List team roles horizontally.
3. Assign RACI codes to each cell:
   - **R**esponsible: Doer of the work.
   - **A**ccountable: Sole decision-maker / owner (Only ONE per task).
   - **C**onsulted: Provides required input.
   - **I**nformed: Kept updated on progress.

## Expected Output
A RACI chart.
