# Scenario Planning & Decision Trees Framework

## Definition
Structure alternative futures and compare decision paths using probabilities, outcomes, and expected value.

## When to Use
High-uncertainty decisions.

## Execution Steps
1. Define key uncertainty drivers and decision nodes.
2. Construct Decision Tree branches representing choice paths and potential outcomes.
3. Assign probabilities ($P$) to outcome branches ($\sum P = 1.0$).
4. Calculate Expected Value ($\text{EV} = \sum (\text{Probability} \times \text{Financial Impact})$).
5. Select path yielding highest risk-adjusted EV.

## Expected Output
A preferred option across scenarios with expected value.
