# OKRs Framework

## Definition
Set qualitative Objectives supported by measurable Key Results.

## When to Use
Goal setting or execution cadence.

## Execution Steps
1. Define 3-5 qualitative, ambitious **Objectives**.
2. Define 3-5 quantitative **Key Results** per Objective (measuring outcomes, not tasks).
3. Cascade OKRs across company, department, and team levels.
4. Review progress weekly/quarterly.

## Expected Output
A cascaded OKR set with tracking.
