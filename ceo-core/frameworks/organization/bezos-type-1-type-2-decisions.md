# Bezos Type 1 / Type 2 Decisions Framework

## Definition
Classify irreversible, high-cost decisions as Type 1 and reversible, low-cost decisions as Type 2.

## When to Use
Any decision requiring an escalate-or-act determination.

## Execution Steps
1. Evaluate decision reversibility.
2. **Type 1 (One-Way Door):** Irreversible decision. Require thorough analysis, consensus, and executive review.
3. **Type 2 (Two-Way Door):** Reversible decision. Delegate down, act quickly with ~70% information.

## Expected Output
A decision classification with recommended decision speed.
