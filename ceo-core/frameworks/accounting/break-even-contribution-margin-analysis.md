# Break-Even & Contribution Margin Analysis Framework

## Definition
Determine the volume at which total contribution margin equals fixed costs.

## When to Use
Pricing or volume decisions.

## Execution Steps
1. Calculate Contribution Margin per Unit ($\text{Price} - \text{Variable Cost}$).
2. Calculate Contribution Margin Ratio ($\text{Contribution Margin} / \text{Price}$).
3. Calculate Break-Even Units ($\text{Fixed Costs} / \text{Contribution Margin per Unit}$).
4. Calculate Break-Even Sales Revenue ($\text{Fixed Costs} / \text{Contribution Margin Ratio}$).

## Expected Output
A break-even point with sensitivity analysis.
