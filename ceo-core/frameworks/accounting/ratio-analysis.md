# Ratio Analysis Framework

## Definition
Analyze liquidity, profitability, efficiency, leverage, and coverage ratios.

## When to Use
Performance monitoring or benchmarking.

## Execution Steps
1. **Liquidity Ratios:** Current Ratio, Quick Ratio.
2. **Profitability Ratios:** Gross Margin, Operating Margin, Net Margin, ROA, ROE.
3. **Efficiency Ratios:** Inventory Turnover, Asset Turnover.
4. **Leverage/Coverage Ratios:** Debt-to-Equity, Interest Coverage Ratio.
5. Benchmark against historical trends and industry peers.

## Expected Output
A ratio dashboard with trends and red flags.
