# Jobs-to-be-Done Framework

## Definition
Describe the progress customers seek when they hire a product or service.

## When to Use
Innovation or positioning.

## Execution Steps
1. Identify the core functional, emotional, and social job the buyer is trying to accomplish.
2. Document current workarounds and pain points.
3. Draft Job Statements ("When [situation], I want to [motivation], so that I can [expected outcome]").
4. Align product features to satisfy the unmet job criteria.

## Expected Output
Job statements with solution criteria.
