# Domain-Driven Design (Strategic Patterns) Framework

## Definition
Decompose complex domains using bounded contexts, ubiquitous language, and context mapping.

## When to Use
Complex domain modeling or system decomposition.

## Execution Steps
1. Define Ubiquitous Language shared by domain experts and developers.
2. Identify Bounded Contexts (logical domain boundaries).
3. Map Context Relationships (Upstream/Downstream, Customer/Supplier, Anti-Corruption Layer).
4. Assign team ownership to distinct Bounded Contexts.

## Expected Output
A bounded-context map.
