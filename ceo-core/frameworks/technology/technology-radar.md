# Technology Radar Framework

## Definition
Govern technology choices by categorizing tools and techniques as Adopt, Trial, Assess, or Hold.

## When to Use
Technology-choice governance.

## Execution Steps
1. Audit current technology portfolio across Techniques, Tools, Platforms, and Languages/Frameworks.
2. Categorize into 4 concentric rings:
   - **Adopt:** Production standard.
   - **Trial:** Low-risk production project evaluation.
   - **Assess:** R&D research.
   - **Hold:** Avoid for new projects.

## Expected Output
A categorized adoption recommendation.
