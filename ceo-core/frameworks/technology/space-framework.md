# SPACE Framework

## Definition
Assess developer productivity across Satisfaction, Performance, Activity, Communication and Collaboration, and Efficiency and Flow.

## When to Use
Broader developer productivity assessment beyond activity metrics.

## Execution Steps
1. **Satisfaction & Well-being:** Survey developer burn-out and tool friction.
2. **Performance:** Evaluate output quality and impact.
3. **Activity:** Count volume of commits, PRs, and deployments.
4. **Communication & Collaboration:** Assess documentation quality and code review speed.
5. **Efficiency & Flow:** Measure uninterrupted focus time and velocity limits.

## Expected Output
A multi-dimension productivity view.
