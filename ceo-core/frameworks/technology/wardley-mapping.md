# Wardley Mapping Framework

## Definition
Map value-chain components against evolution stages of genesis, custom, product, and commodity to guide sourcing choices.

## When to Use
Technology strategy and sourcing decisions.

## Execution Steps
1. Anchor the map on User Needs.
2. Draw the Value Chain vertically (from visible user touchpoints to hidden infrastructure).
3. Map components horizontally across 4 evolution stages: **Genesis**, **Custom Built**, **Product/Service**, **Commodity/Utility**.
4. Evaluate strategic moves and sourcing options.

## Expected Output
A positioned value-chain map with strategic implications.
