# SRE Principles Framework

## Definition
Guide reliability through error budgets, service-level objectives and indicators, toil reduction, and blameless postmortems.

## When to Use
Reliability decisions and incident-response posture.

## Execution Steps
1. Define Service Level Indicators (SLIs) (e.g., latency, error rate).
2. Establish Service Level Objectives (SLOs) (e.g., 99.9% uptime).
3. Derive Error Budget ($100\% - \text{SLO}$).
4. Eliminate Toil via automation scripts.
5. Execute Blameless Postmortems after incidents.

## Expected Output
A reliability target with operating discipline.
