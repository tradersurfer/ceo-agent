# Threat Modeling (STRIDE) Framework

## Definition
Identify security risks systematically using STRIDE or an equivalent threat categorization method.

## When to Use
Security-relevant technical decisions.

## Execution Steps
1. Map System Architecture and Trust Boundaries.
2. Evaluate threats across STRIDE categories:
   - **S**poofing Identity
   - **T**ampering with Data
   - **R**epudiation
   - **I**nformation Disclosure
   - **D**enial of Service
   - **E**levation of Privilege
3. Formulate mitigation controls for each identified threat.

## Expected Output
Identified threat categories with mitigations.
