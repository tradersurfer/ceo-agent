# Working Capital / Cash Conversion Cycle Framework

## Definition
Measure operating cash efficiency using $\text{CCC} = \text{DIO} + \text{DSO} - \text{DPO}$.

## When to Use
Cash-flow optimization or funding growth.

## Execution Steps
1. Calculate Days Inventory Outstanding ($\text{DIO}$).
2. Calculate Days Sales Outstanding ($\text{DSO}$).
3. Calculate Days Payable Outstanding ($\text{DPO}$).
4. Compute $\text{CCC} = \text{DIO} + \text{DSO} - \text{DPO}$.
5. Identify levers to lower DSO, optimize DIO, and extend DPO without hurting supplier terms.

## Expected Output
A cash-conversion-cycle trend with improvement levers.
