# DCF / NPV / IRR Framework

## Definition
Value an investment using projected free cash flows discounted at WACC or the required return.

## When to Use
Capital budgeting, mergers and acquisitions, or valuation.

## Execution Steps
1. Forecast unlevered free cash flows over a 5-10 year horizon.
2. Calculate the Terminal Value using perpetual growth or exit multiple methods.
3. Discount all cash flows to present value using WACC.
4. Calculate Net Present Value (NPV) and Internal Rate of Return (IRR).
5. Perform sensitivity analysis across key revenue and cost drivers.

## Expected Output
NPV, IRR, and sensitivity analysis.
