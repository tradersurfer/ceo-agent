# 9-Box Grid Framework

## Definition
Assess talent on a grid of demonstrated performance against assessed potential to inform development and succession reasoning.

## When to Use
Talent review, succession planning, or development prioritization.

## Execution Steps
1. Plot employees on 3x3 matrix:
   - Vertical Axis: Performance (Low, Medium, High).
   - Horizontal Axis: Potential (Low, Medium, High).
2. Identify High-Potentials / Stars (Top Right).
3. Draft tailored retention, succession, or performance plans for each quadrant.

## Expected Output
A placement rationale with development or succession actions per segment.
