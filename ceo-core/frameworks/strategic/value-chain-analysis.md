# Value Chain Analysis Framework

## Definition
Examine primary and support activities to identify sources of cost or differentiation advantage.

## When to Use
Competitive-advantage diagnosis or cost reduction.

## Execution Steps
1. Map **Primary Activities:** Inbound Logistics, Operations, Outbound Logistics, Marketing & Sales, Service.
2. Map **Support Activities:** Infrastructure, HR Management, Technology Development, Procurement.
3. Assign costs and value drivers to each activity.
4. Identify differentiation opportunities or cost-reduction levers.

## Expected Output
An activity-level cost and value map.
