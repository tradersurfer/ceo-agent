# Hypothesis-Driven Problem Solving Framework

## Definition
Start with a hypothesis, structure the problem in MECE form, and test the branches with data.

## When to Use
Complex problem-solving.

## Execution Steps
1. Formulate an initial "Early Answer" hypothesis.
2. Construct a MECE issue tree to identify the conditions required for the hypothesis to be true.
3. Define key analyses required to test each branch.
4. Gather data, run tests, and revise or confirm the hypothesis.

## Expected Output
A validated or falsified hypothesis supported by evidence.
