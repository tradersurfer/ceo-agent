# Theory of Constraints Framework

## Definition
Identify the system's bottleneck and subordinate, exploit, and elevate it to increase throughput.

## When to Use
Throughput maximization.

## Execution Steps
1. **Identify** the system constraint (the single slowest bottleneck).
2. **Exploit** the constraint (maximize output using existing capacity).
3. **Subordinate** everything else to the constraint (align all non-bottlenecks to feed the constraint).
4. **Elevate** the constraint (invest capital to expand capacity).
5. **Repeat** (prevent inertia; find the next constraint).

## Expected Output
Constraint identification with an elevation plan.
