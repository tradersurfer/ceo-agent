# SCOR Model Framework

## Definition
Assess supply-chain performance through Plan, Source, Make, Deliver, and Return.

## When to Use
Supply-chain design or performance improvement.

## Execution Steps
1. Analyze process across 5 core pillars: **Plan**, **Source**, **Make**, **Deliver**, **Return**.
2. Measure metrics across Reliability, Responsiveness, Agility, Cost, and Asset Management Efficiency.
3. Benchmark performance against industry peers.
4. Design future-state process maps and technology integration roadmap.

## Expected Output
Process metrics with an improvement roadmap.
