# AARRR (Pirate Metrics) Framework

## Definition
Measure Acquisition, Activation, Retention, Revenue, and Referral.

## When to Use
Digital or growth optimization.

## Execution Steps
1. **Acquisition:** Measure traffic sources and landing page conversion rates.
2. **Activation:** Measure user "Aha!" moment drop-off rates.
3. **Retention:** Measure cohort retention curves over 30/60/90 days.
4. **Revenue:** Track ARPU, expansion MRR, and churn.
5. **Referral:** Measure Viral Coefficient ($K$-factor) and Net Promoter Score.

## Expected Output
Funnel diagnostics.
