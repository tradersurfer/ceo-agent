# MECE Principle Framework

## Definition
Group information into categories that are mutually exclusive and collectively exhaustive: non-overlapping and complete.

## When to Use
Any complex problem breakdown or issue-tree construction.

## Execution Steps
1. Define the core problem statement clearly.
2. Break down the problem into primary, non-overlapping buckets (Mutually Exclusive).
3. Verify that the combined buckets account for 100% of possibilities (Collectively Exhaustive).
4. Subdivide each bucket iteratively following the same MECE rules.

## Expected Output
A clean, non-redundant issue tree or category set.
