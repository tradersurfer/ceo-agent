# Pyramid Principle Framework

## Definition
Lead with the governing thought, followed by MECE-grouped supporting arguments.

## When to Use
All executive communication.

## Execution Steps
1. **Top Level:** State the main answer/recommendation in sentence 1.
2. **Second Level:** Provide 3-4 MECE supporting core arguments.
3. **Third Level:** Provide underlying facts, data, and evidence.
4. Structure written documents and presentations top-down.

## Expected Output
A clear top-down recommendation structure.
