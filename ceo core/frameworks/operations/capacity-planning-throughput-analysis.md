# Capacity Planning & Throughput Analysis Framework

## Definition
Match available capacity and throughput to current and forecast demand.

## When to Use
Scaling or bottleneck relief.

## Execution Steps
1. Calculate Design Capacity vs. Effective Capacity.
2. Measure Actual Throughput and Utilization Rate.
3. Forecast demand scenarios.
4. Identify capacity gaps and model expansion timing (Lead, Lag, or Match strategies).

## Expected Output
A capacity model with a utilization plan.
