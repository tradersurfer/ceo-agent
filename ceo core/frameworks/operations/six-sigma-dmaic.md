# Six Sigma / DMAIC Framework

## Definition
Reduce process variation through Define, Measure, Analyze, Improve, and Control.

## When to Use
Process-variation reduction.

## Execution Steps
1. **Define:** Scope the problem, baseline goals, and customer requirements (CTQ).
2. **Measure:** Collect process data and assess measurement system validity.
3. **Analyze:** Identify root causes of defect variation.
4. **Improve:** Develop and implement solutions to eliminate root causes.
5. **Control:** Implement monitoring controls to maintain gains.

## Expected Output
Statistical process control with improved capability.
