# Lean / Toyota Production System Framework

## Definition
Improve flow by eliminating waste through kaizen, just-in-time practices, and pull systems.

## When to Use
Process efficiency or lead-time reduction.

## Execution Steps
1. Define Value from the customer perspective.
2. Map the Value Stream and spot the 7 Wastes (Muda: Transport, Inventory, Motion, Waiting, Overproduction, Overprocessing, Defects).
3. Establish continuous process flow.
4. Implement Pull systems (Kanban) to match production to customer demand.
5. Pursue perfection via continuous incremental improvement (Kaizen).

## Expected Output
A value-stream map with waste-reduction actions.
