# DuPont Analysis Framework

## Definition
Decompose return on equity into margin, asset turnover, and equity multiplier.

## When to Use
Performance diagnosis or benchmarking.

## Execution Steps
1. Calculate Net Profit Margin ($\text{Net Income} / \text{Revenue}$).
2. Calculate Asset Turnover ($\text{Revenue} / \text{Total Assets}$).
3. Calculate Financial Leverage / Equity Multiplier ($\text{Total Assets} / \text{Shareholder Equity}$).
4. Multiply elements: $\text{ROE} = \text{Net Profit Margin} \times \text{Asset Turnover} \times \text{Equity Multiplier}$.
5. Diagnose whether ROE changes are driven by profitability, efficiency, or debt leverage.

## Expected Output
A driver breakdown of changes in return on equity.
