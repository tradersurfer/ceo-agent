# Competing Values Framework

## Definition
Diagnose organizational culture across four quadrants — Clan, Adhocracy, Market, and Hierarchy — defined by internal-versus-external focus and flexibility-versus-control.

## When to Use
Culture diagnosis, culture change, or leadership-style alignment.

## Execution Steps
1. Audit culture across two axes: Flexibility vs. Control and Internal Focus vs. External Focus.
2. Map current culture mix:
   - **Clan:** Collaborate / Family.
   - **Adhocracy:** Create / Innovate.
   - **Market:** Compete / Deliver.
   - **Hierarchy:** Control / Process.
3. Formulate shift interventions to match strategic goals.

## Expected Output
A current-versus-target culture profile with the shift required.
