# Activity-Based Costing Framework

## Definition
Allocate overhead according to the activities and cost drivers that actually consume resources.

## When to Use
Accurate product or service costing.

## Execution Steps
1. Identify major overhead activities.
2. Assign overhead costs to activity cost pools.
3. Identify cost drivers for each activity (e.g., machine hours, order counts).
4. Calculate activity cost rates.
5. Assign costs to products/services based on consumption of cost drivers.

## Expected Output
True cost and margin by activity.
