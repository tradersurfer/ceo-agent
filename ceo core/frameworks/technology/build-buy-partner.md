# Build vs Buy vs Partner Framework

## Definition
Compare sourcing options using total cost of ownership, differentiation, and risk.

## When to Use
Sourcing decisions.

## Execution Steps
1. Assess core differentiation (Is this software a primary competitive advantage?).
2. Calculate Total Cost of Ownership (TCO) across initial build, maintenance, security, and hosting.
3. Evaluate market vendors (Buy) and potential integrations (Partner).
4. Make structured decision recommendation based on core competency and speed-to-market goals.

## Expected Output
A recommended sourcing path with rationale.
