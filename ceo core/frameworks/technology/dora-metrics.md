# DORA Metrics Framework

## Definition
Assess software delivery through Deployment Frequency, Lead Time for Changes, Change Failure Rate, and Time to Restore Service.

## When to Use
Software delivery performance assessment.

## Execution Steps
1. **Deployment Frequency:** Measure how often code is deployed to production.
2. **Lead Time for Changes:** Measure time from commit to production release.
3. **Change Failure Rate:** Calculate percentage of deployments causing production outages.
4. **Time to Restore Service:** Calculate mean time to recover (MTTR) from incidents.
5. Categorize team performance: Low, Medium, High, or Elite performer.

## Expected Output
A four-metric delivery health snapshot.
