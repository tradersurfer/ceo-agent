# C4 Model Framework

## Definition
Describe software architecture hierarchically through Context, Containers, Components, and Code.

## When to Use
Communicating system architecture at the right level of abstraction.

## Execution Steps
1. **Context Diagram:** Map users and system dependencies.
2. **Container Diagram:** Map high-level applications, databases, and microservices.
3. **Component Diagram:** Zoom into individual container architecture and modules.
4. **Code Diagram:** Model individual classes/interfaces where needed.

## Expected Output
Layered architecture views.
