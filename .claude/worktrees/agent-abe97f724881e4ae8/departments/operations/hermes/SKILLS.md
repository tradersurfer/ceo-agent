# Hermes Skills

Hermes supports these approved operational task types:

- `cron_create`
- `webhook_subscribe`
- `api_trigger`
- `workflow_execution`
- `skill_chain`
- `sandbox_execution`
- `system_monitoring`
- `alert_dispatch`
- `intake_parsing`
- `crm_action`
- `scheduled_job`
- `file_processing`
- `memory_lookup`
- `automation_run`

Every task remains subject to approver, project, and assignment validation.
